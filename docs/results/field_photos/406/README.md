# 406 mm field-test photographs

These photographs document the physical 406 mm pipe pull-test and in-line
inspection setup used by the project team. They provide visual context only.
Neither image is consumed by the signal-processing pipeline or used as
quantitative evidence for magnetic, remanence, eddy-current or strain results.

## Deterministic publication processing

- The embedded `Display P3` source profile was transformed to sRGB with
  LittleCMS using the perceptual rendering intent.
- Images were resized with the Lanczos filter without upscaling.
- The first photograph was limited to a 1000 px longest edge because two
  people are present in the distant background. The second was limited to a
  1600 px longest edge.
- Both copies were encoded as baseline JPEG at quality 90 with 4:2:0 chroma
  subsampling.
- EXIF, GPS, XMP, comments and embedded ICC data were omitted from the
  published copies. After the colour transform, untagged pixels are sRGB.
- No scene content, analytical markings, hardware structures or signal
  features were generated, removed or replaced.
- Processing used Pillow 12.3.0 and LittleCMS 2.19.

The lower-resolution first copy reduces facial detail but is not asserted to
provide formal anonymisation. Reusers remain responsible for any additional
consent or privacy requirements that apply to their publication context.

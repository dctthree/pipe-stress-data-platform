# 工业采集元数据 SOP

## 每根管道只登记一次

- `pipe_id`：永久唯一编号，不使用“新管道1”一类临时名称。
- 材质、炉批、制造方法、长度、外径、壁厚、屈服和抗拉强度。
- 坐标原点、轴向正方向、从哪一端观察定义钟点方向。
- 焊缝、缺陷、压头和支墩的物理坐标及测量不确定度。

## 每种探头配置只登记一次

- `probe_id`、探头序列号和传感器布局版本。
- MEM/剩磁/零磁/ETP 类型；磁极完整、单侧开槽或双侧对称开槽。
- 左右磁极尺寸、槽宽/槽深、线圈匝数、电流和磁化方向。
- 盖板材料/厚度、名义提离、传感器到磁极及管壁的几何位置。
- 每一列对应的传感器、轴、单位、增益、量程、极性和校准证书。

## 每次牵拉必须登记

- `experiment_id / run_id / cycle_id / stage_id / pull_id`。
- 日期时间、操作者、环境温度和仪器软件版本。
- 加载/卸载/恢复分支；指令位移、实测位移、载荷；零载也必须是一条正式记录。
- 6/12点或准确角度；牵拉方向；牵拉速度及其波动。
- 采样率、编码器零点与脉冲当量、磁化电流、实时提离/姿态（如有）。
- 原始数据文件、应变文件和实验记录文件。
- 异常事件：停顿、摩擦尖峰、掉电、通道饱和、探头碰撞或人工重拉。

## 文件到达规则

1. 数据采集完成后立即关闭文件，复制到 `01_incoming/<experiment_id>/`。
2. 填写 intake manifest 后执行导入；原始文件生成 SHA-256。
3. 哈希相同视为同一内容，不重复保存；同名但哈希不同必须生成新版本并报警。
4. 无法解析、缺少探头布局或工况映射的文件进入隔离状态，禁止进入模型。
5. 原始层只读；任何修正都在元数据或派生层完成并保留修订理由。

## 标签治理

- 应变原始值、零点修正值、异常标记和应力换算值分别保存。
- `-1` 明确登记为环向、`-3` 明确登记为轴向；不得由模型脚本临时猜测。
- 盲测标签在预测冻结前不可被特征选择、ROI选择或阈值调整程序读取。
- 标签异常只标记，不删除原记录；`use_for_supervised=false`。
- 应力标签公式、弹性模量、泊松比、采用的12/6配对和标签版本必须可追溯。

## AI 数据划分

最小分组键为 `pipe_id + experiment_id + run_id`。同一轮的全部阶段、6/12点和所有传感模态必须进入同一折，禁止按采样点、窗口或单个CSV随机拆分。只有从未参与特征筛选和阈值选择的新管道，才可称为工程盲测。

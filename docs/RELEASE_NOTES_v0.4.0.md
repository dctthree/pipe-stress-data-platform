# v0.4.0 — open licensing, citation and community release

Release date: 2026-08-29

## What changed

- software code is now licensed under Apache License 2.0;
- experimental data, public tables, result figures and field photographs are licensed under CC BY 4.0 unless stated otherwise;
- `CITATION.cff` and `.zenodo.json` identify Bin Gao, UESTC, as the author/creator;
- the English and Chinese landing pages now expose real-data, licence, citation and reproduction entry points;
- GitHub Topics, Discussions and structured reproduction/data/method issue forms are enabled;
- CI uses the Node 24 generations of the official checkout and Python setup actions.

## Data-version boundary

This platform release does not replace or silently rewrite the frozen real-data assets:

- P110 EXP2 remains frozen as data release `v0.2.0`;
- 406 calibration and blind repeats remain frozen as data release `v0.3.0`.

The scientific claim limits of those releases remain unchanged. Version `v0.4.0` adds reuse rights, citation metadata and community infrastructure; it does not claim independent-pipe absolute stress validation.
